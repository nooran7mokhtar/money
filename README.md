# Pouch

Split your salary into pouches for spending and saving.

- **Spending pouches** reset every month and show what's left.
- **Savings pouches** build up, with an optional goal and a months-to-go estimate.
- **Installments** count down payments left.
- **Payday** fills every savings pouch in one tap; **Close month** moves leftovers to the savings pouch you choose.

Your data stays on your device. Use **Setup → Download backup** regularly.

Open it in Safari, then **Share → Add to Home Screen** to use it like an app.
